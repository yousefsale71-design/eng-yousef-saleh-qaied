# موقع المهندس يوسف صالح قايد – خدمات هندسية واستشارية عن بُعد
## Eng. Yousef Saleh Qaid – Architectural & Engineering Consulting Services

موقع إلكتروني احترافي متكامل لتقديم الخدمات الهندسية والاستشارية والمعمارية عن بُعد في اليمن ومختلف الدول، من تصميم وإظهار معماري ومخططات تنفيذية وحصر كميات واستشارات هندسية متخصصة.

---

## 🌟 مميزات الموقع (Key Features)

- **الصفحة الرئيسية (Homepage):** عرض ترحيبي متكامل بالمهندس يوسف صالح قايد، الشعار الدعائي، إحصائيات الخبرة (+10 سنوات، +120 مشروع)، ملخص الخدمات الأساسية، معرض مشاريع مختارة، آلية العمل الهندسية (5 مراحل)، آراء العملاء والأسئلة الشائعة.
- **صفحة الخدمات (Services):** شرح مفصل ومصنف للخدمات الخمس مع البرامج المستخدمة (Revit, AutoCAD, Lumion 3D)، المخرجات المسلمة (Deliverables)، وقوائم الميزات وإمكانية الطلب المباشر.
- **معرض الأعمال (Portfolio / Projects):** استعراض شامل لمشاريع الفلل، المباني التجارية، التصاميم الداخلية، ورندرات Lumion مع فلاتر حسب التصنيف، شريط بحث ذكي، ونافذة منبثقة تفاعلية (Modal) لاستعراض تفاصيل المشروع والألبوم.
- **نبذة عني والسيرة الذاتية (About Me / CV):** السيرة المهنية للمهندس (بكالوريوس هندسة معمارية 2024 بتقدير جيد جداً 80.13%)، خط زمني لأكثر من 10 سنوات خبرة ميدانية، المهارات ومستويات إتقان البرمجيات الهندسية.
- **نموذج طلب خدمة (Request Service):** نموذج متكامل لطلب الخدمات الهندسية يتيح إدخال بيانات العميل، نوع الخدمة، موقع ومساحة المشروع، وصف المتطلبات، ورفع ملفات ومخططات كروكي مدعوم بـ **Netlify Forms**.
- **اتصل بنا (Contact Us):** معلومات التواصل المباشر (الهاتف، البريد، واتساب، موقع صنعاء - اليمن)، أوقات العمل، ونموذج مراسلة سريعة.
- **زر واتساب عائم (Floating WhatsApp):** متاح في جميع صفحات الموقع للتواصل والاستشارة الفورية مع المهندس (+967 782842655).
- **تصميم هندسي متجاوب (Responsive & Architectural Design):** متوافق مع كافة الشاشات والموبايل، اتجاه RTL معتمد مع خطوط عربية حديثة (Cairo)، وألوان هندسية فخمة (كحلي داكن، ذهبي برونزي، وأبيض ناصع).

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Framework:** TanStack Start (React 19 + TypeScript)
- **Routing:** TanStack Router (Type-Safe Routing)
- **Styling:** Tailwind CSS 4 + Modern CSS Custom Properties
- **Forms & Serverless:** Netlify Forms (AJAX submissions with static detection)
- **Icons:** Lucide React
- **Typography:** Google Fonts (Cairo & Tajawal)

## 🚀 تشغيل المشروع محلياً (Local Development)

1. تثبيت الحزم:
   ```bash
   pnpm install
   ```

2. تشغيل خادم التطوير:
   ```bash
   pnpm dev
   ```

3. بناء المشروع للإنتاج:
   ```bash
   pnpm build
   ```
